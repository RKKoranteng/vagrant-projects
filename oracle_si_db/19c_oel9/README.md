# Oracle 19c on OEL9

A simple Vagrant build for Oracle Database 19c on OEL9

## Required Software

* [Vagrant](https://www.vagrantup.com/downloads.html)
* [VirtualBox](https://www.virtualbox.org/wiki/Downloads)
* [Oracle Database 19c](#)

## Quickstart
1. Create folder to share between host and VM using `mkdir -p $HOME\Downloads\VagrantShare`
1. Place the Oracle database software in the "VagrantShare" directory
1. Create VM using `vagrant up` command
